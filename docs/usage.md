# CoreXの使い方

左右にCoreX用ファームを書き込んだセット向けの案内です。以下のキー操作はv0.11.3の初期配列を基準にしています。Vialで割り当てを変えている場合は、変更後のキーを使ってください。この版の実機確認状況は[検証状況](validation.md)に記載しています。

## USBで接続する

1. 左右の電源をONにします。
2. **右側をPCにUSB接続**します。左は無線で右につながります。
3. 左右のキーで文字を入力します。

USBケーブルはデータ通信対応のものを使います。左をUSB接続しても、PCへのキー入力やVialでの設定はできません。

左右の登録がまだないセットは、左右のRESETを1回ずつ続けて押すと、起動後60秒間に相手を探して登録します。この間は1セットだけ起動してください。左のキーから文字が入力できれば接続完了です。登録済みのセットでは、電源ONで再接続するためRESETは不要です。

## Bluetoothで接続する

左右に充電済みの電池をつなぎ、電源をONにします。PCに登録するのは右側の **Cornix TB** です。左右同士の登録とは別に行います。

1. 右親指の接続キー（初期配列の **MO(6)**、Spaceの隣）を押しながら、**Yを短く押して離します**。PCの登録先1を選びます。
2. PCのBluetooth設定で **Cornix TB** を選んで登録します。
3. 右のUSBケーブルを抜き、左右のキーとボールが動くことを確認します。

登録済みのPCは、その登録先を選べば再接続します。登録先に別のPCの情報が残っている場合は、空いている登録先を使うか、[PCの登録をやり直します](#pcの登録をやり直す)。

### 接続するPCを切り替える

登録先は3つです。右親指の **MO(6)** を押しながら次のキーを操作します。MO(6)は操作が終わるまで押したままにします。

| 右のキー | 操作 |
| --- | --- |
| Y / U / Iを短く押す | 登録先1 / 2 / 3へ切り替え |
| Oを短く押す | 次の登録先へ切り替え |
| Pを短く押す | USB／Bluetoothの優先出力を切り替え |
| Backspaceを5秒長押し | 現在のPC登録を解除 |
| Hを5秒長押し | 左右の登録をやり直す |

左から切り替える場合は、左親指の中央のBluetoothキー（**MO(4)**）を押しながら、Caps Lock／左Shift／左Ctrlを短く押すと登録先1／2／3を選べます。登録先の選択キーを長押ししても登録は消えません。

初期状態ではUSBを優先します。USBとBluetoothの両方が接続中のときは、Pで選んだ優先出力を使い、その選択は再起動後も残ります。片方だけ接続していれば、その接続先へ入力します。USBを挿したのに別のPCへ入力される場合は、MO(6)＋Pで切り替えます。

### PCの登録をやり直す

1. PCのBluetooth設定で、このキーボードの登録を削除します。旧版の名前が表示されている場合も、同じ本体の登録を選びます。
2. MO(6)＋Y／U／Iで、削除したい登録先を選びます。
3. MO(6)を押したまま、Backspaceを5秒長押しして離します。長押し中はほかのキーを操作しません。
4. PCのBluetooth設定で **Cornix TB** を選び、登録し直します。

解除されるのは選択中のPC登録だけです。キー配列、ほかのPC登録、左右の登録は残ります。PC側の登録を削除しただけでは本体側の登録は消えないため、両方の操作を行います。

割り当てを変更して接続キーがない場合は、右をUSB接続し、Vialの **User** タブで「BLE 1」〜「BLE 3」と「PC登録 解除」をキーへ割り当てます。対象の登録先を選び、「PC登録 解除」を5秒長押ししてください。

## トラックボールを使う

- **ポインター移動：** ボールを回します。
- **クリック：** ボールを動かした直後に、Jで左クリック、Kで中クリック、Lで右クリックします。
- **スクロール：** Iを長押ししながらボールを回します。縦・横のスクロールに対応しています。
- **Iの文字入力：** Iを短く押して離します。

ボール操作によるクリックへの自動切り替えを「AML（オートマウス）」と呼びます。初期値はONで、ボールを止めて約0.7秒後に文字入力へ戻ります。クリックを続けるとこの時間は延長されます。J・K・L以外の文字キーなどを押すと解除されます。

自動切り替えを使わない場合は、VialでAMLをOFFにします。OFFでも、Iを押し続けている間はスクロールとJ・K・Lのクリックを使えます。Iの長押し判定は初期値200msで、ほかのキーとの組合せによって早まる場合があります。

右のダイヤルはスクロールと押し込みによる中クリック、左のダイヤルは音量調整と押し込みによるミュートに割り当てられています。

## Vialで設定する

1. [Vial](https://get.vial.today/)を開き、右側をUSBでPCにつなぎます。
2. 機器一覧から **CoreX** を選びます。ほかのVial画面や設定アプリは閉じます。
3. 上の配列から変更するキーを選び、下の候補を選びます。変更は本体へ反映されます。

左右の配列は右側でまとめて管理します。Bluetoothでの通常入力と、設定アプリからの通信は別の機能です。この案内ではUSB接続で設定します。[Vialの基本操作](https://get.vial.today/manual/first-use.html)

### 感度・スクロール量・AML

**Layer 0** の「感度」「Scroll」「AML」欄を選び、下の **User** タブから値を選びます。これらは設定専用の欄で、実物のキーではありません。

| 項目 | 選択肢 | 初期値 |
| --- | --- | --- |
| 感度 | 0.5／1／1.5／2／3／4倍 | 2倍 |
| Scroll | 停止／最速／速い／標準／遅い／微速 | 標準 |
| AML | ON／OFF | ON |

Scrollはボールのスクロール量を変更し、ダイヤルには影響しません。OS側のポインター速度やスクロール設定も操作感に影響します。

### 保存・読み込みとロック解除

現在の配列は **File → Save current layout** で `.vil` に保存できます。保存した配列は **File → Load saved layout** で読み込みます。CoreX用と純正Cornix用のファイルは区別してください。

マクロ、キーテスター、設定消去や再起動に関わる操作にはロック解除が必要です。**Security → Unlock** を選び、右の **YとBackspaceの物理位置**を、画面の進捗バーが完了するまで同時に押し続けます。割り当てを変更していても位置は同じです。

自分で保存した配列を読み込む場合も、保護対象の割り当てを復元できるよう先に解除します。終了後はVialでロックするか、本体を再起動します。同梱の[初期配列](../keymaps/README.md)には保護対象のキーやマクロを含めていません。

## 左右の登録をやり直す

左を交換したときや、以前の別セットの登録が残っているときに使います。通常の更新、一時的な切断、PCの再登録では不要です。

1. 右親指の **MO(6)** を押したまま、**Hを5秒長押し**します。長押し中はほかのキーを操作しません。
2. 左右がつながっていた場合は、左の登録も解除してつなぎ直します。左が不在・未接続だった場合や交換する場合は、つなぐ左の **TabとTの物理位置を同時に5秒長押し**します。
3. 左のキーで入力を確認します。60秒以内につながらなければ、右と未接続の左で上の操作を繰り返します。

操作中は登録する1セットだけを起動します。キー配列とPCの登録は残ります。右の割り当てを変えている場合は、VialのUserタブで「左右登録 リセット」を任意のキーに割り当て、5秒長押しします。

## 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 左だけ入力できない | 左の電源・充電・CoreX用ファームを確認します。初回の60秒が過ぎた場合は左右のRESETを1回ずつ押します。別セットの登録が残っていれば、上の登録手順を使います。 |
| Vialに表示されない | 右をデータ通信対応のUSBケーブルでつなぎます。書き込み用ドライブが出ている場合はRESETを1回押して通常起動します。ほかの設定アプリを閉じて再接続します。 |
| Bluetoothで見つからない | 使用する登録先を選びます。別のPCに登録済みなら空き登録先を使います。入力しても見つからず、登録情報が食い違う場合はPCと本体の両方で登録をやり直します。 |
| USB接続中なのに別のPCへ入力される | MO(6)＋Pで優先出力を切り替えます。 |
| J・K・Lが文字にならない | ボールを止めて約0.7秒待ちます。自動切り替えが不要ならAMLをOFFにします。 |
| クリックできない | AMLがONなら、ボールを動かした直後にJ・K・Lを押します。Iの長押し中もクリックできます。 |
| ボールでスクロールできない | Iを長押しし、Scrollが「停止」になっていないことを確認します。 |

RESETを1回押すと再起動、素早く2回押すと書き込みモードです。どちらもキー配列やBluetooth登録の削除操作ではありません。

解決しない場合は[Issues](https://github.com/yuchamichami/CoreX-RMK/issues)へ、左右の基板とファームの版、PCのOS、USB／Bluetoothのどちらで起きるか、再現する操作を記載してください。Bluetoothのアドレスやシリアル番号を公開する必要はありません。
