# 純正CornixでCoreXを使う（試験版）

Cornix純正の左右基板にCoreXファームを書き込み、CoreX StudioとVialで設定するための試験版です。**純正基板での起動・入力・無線・LEDは、まだ実機確認していません。** 交換基板用とは別のファイルを使います。

## ファイルを選ぶ

[純正Cornix用の配布フォルダ](../firmware/)に、左右のUF2とチェックサムを置いています。

| 基板 | ファイル |
| --- | --- |
| Cornix純正右 | `Cornix-Stock-Right-v0.11.4.uf2` |
| Cornix純正左 | `Cornix-Stock-Left-v0.11.4.uf2` |

純正左用は既存のCoreX用純正左ファームと同じです。右は今回追加しました。**左右ともCoreX用に更新**します。純正ファームやZMKが入った片側とは組み合わせられません。

メーカー配布のCornix LP V1.12と公開基板定義を基準にしています。純正無線ドングルは対象外です。CoreX交換基板用の `CoreX-Right`／`CoreX-Left` は純正基板へ書き込まないでください。

## 書き込みと左右の登録

1. 残したい設定がある場合は、現在使っているVialから保存します。メーカーの復元用ファームも手元に用意します。
2. 更新する側をUSB接続し、RESETを素早く2回押します。表示されたUSBドライブへ、その側に対応するUF2をコピーします。再起動でドライブが消えます。
3. もう片側にも対応するUF2を書き込みます。左右の電源をONにし、**PCへのUSBは右側につなぎます**。
4. 右の **Hと、親指3キーの中央（Spaceの隣、初期配列のMO(4)）** を同時に5秒押して離します。
5. 60秒以内に、左の **TabとT** を同時に5秒押して離します。すでにつながっていた左は、右から登録し直す操作を受け取ります。
6. 左右のキーとダイヤルを試します。左右登録の受付中は青く点滅し、登録と保存が完了すると緑に2秒点灯する設計です。この純正右でのLED表示は実機確認が必要です。

これらの登録用キーは物理位置で判定するため、割り当てを変えても同じ場所を押します。電源ONやRESETだけでは、新しい相手の登録受付は始まりません。

純正ファームの設定領域とCoreXの保存形式は異なります。純正で保存した配列・コンボ・PC登録が自動で引き継がれることは想定していません。戻す場合は、メーカーの左右それぞれの復元ファームと手順を使います。

## StudioとVialで設定する

右をUSB接続し、[CoreX Studio](https://corex-studio.pages.dev/)で「USBで接続」を選びます。純正用CoreXファームを識別すると、純正の50キー（ダイヤル押し込み2個を含む）と10レイヤーが表示されます。キーとダイヤルの割り当て、コンボ、長押し判定を設定できます。設定変更は自動反映です。

トラックボールなどのタブはグレーになります。センサーやジェスチャーの設定は、この純正基板用ファームには含みません。

Vialでの表示名は **CoreX Cornix** です。Vialを使うときはStudioとの同時接続を避けます。ロック解除が必要な場合は右の **YとBackspace** の位置を、Vialの解除表示が完了するまで同時に押します。

初期配列はメーカー公開の10レイヤーとダイヤル割り当てを引き継いでいます。ただしPCとの接続は右が担当し、左右の行列番号とダイヤル番号を入れ替えています。**純正ファーム用やCoreX交換基板用のバックアップを、そのまま読み込まないでください。** 設定後、この純正基板用CoreXから新しく保存します。

## Bluetoothで使う

Bluetoothの表示名は **Cornix CoreX** です。左親指の中央（初期配列のMO(3)）を押しながら、Caps Lock／左Shift／左Ctrlを短く押すと、PCの登録先1／2／3を選べます。PCのBluetooth設定から登録し、USBを抜いて入力を確認します。

PC登録を消したい場合は、まず右をUSB接続し、StudioまたはVialのUser欄で「BLE 1」〜「BLE 3」と「PC登録 解除」を使えるキーに割り当てます。対象の登録先を選び、「PC登録 解除」を5秒押して離します。PC側の登録も削除してから、再登録します。

## 検証状況

ビルド、UF2の書き込み範囲・起動ベクタ、Vialの機種識別、全レイヤーの配列保持、Studioの読み書き先と編集操作を検証しました。実機のUSB認識、全キー、ダイヤル方向、左右登録、LED色、Bluetooth再接続、スリープ復帰・電池残量は未確認です。実機確認が終わるまでは試験版として扱います。

ピンの根拠とビルド方法は[開発用の検証記録](cornix-stock-validation.md)にまとめています。
