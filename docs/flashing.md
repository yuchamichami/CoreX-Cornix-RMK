# ファームウェアを書き込む

更新する場合、またはCornix純正左を初めてCoreX右と組み合わせる場合の手順です。左右ともCoreX v0.11.4を書き込み済みのセットを使い始める場合は、[使い方](usage.md)へ進んでください。

## ファイルを選ぶ

[firmwareフォルダ](../firmware/)から、基板に合うUF2をダウンロードします。GitHubのファイル画面では **Download raw file** を使います。現行のv0.11.4は実機最終確認前のプレリリースです。[検証状況](validation.md)

| 基板 | ファイル名 | ブートローダの確認 |
| --- | --- | --- |
| CoreX R A14 | `CoreX-Right-v0.11.4-s140v6.uf2` または `s140v7` | 下記のSoftDevice版を確認 |
| CoreX L Rev1.0 | `CoreX-Left-v0.11.4-s140v6.uf2` または `s140v7` | 下記のSoftDevice版を確認 |
| Cornix 純正左 | `Cornix-Stock-Left-v0.11.4.uf2` | 専用ファイルを使用 |

**左右・CoreX左・Cornix純正左のファイルは入れ替えられません。** Cornix純正右やCoreX-Proto-RMKの試作基板も対象外です。基板の種類が分からない場合は、購入時の製品案内と基板表示を確認してください。

新しい左右登録手順と成功LEDの表示を使うには、**右・左の両方をv0.11.4へ更新**してください。

この手順は、UF2用のブートローダが入っている基板向けです。未書き込みのマイコンへのブートローダ導入は含みません。

### CoreX基板のSoftDevice版

CoreX基板だけをUSBで接続してRESETを素早く2回押し、現れたドライブ内の `INFO_UF2.TXT` を開きます。SoftDeviceのバージョンでファイルを選びます。

- **S140 6.x：** 末尾が `s140v6.uf2` のファイル。
- **S140 7.x：** 末尾が `s140v7.uf2` のファイル。この組合せは実機未確認です。
- **記載がない／判別できない：** 別の版を試す前に、購入時のブートローダ情報を確認します。判断できない場合は[Issues](https://github.com/yuchamichami/CoreX-RMK/issues)へ、シリアル番号を除いた `INFO_UF2.TXT` の内容を添えて問い合わせてください。

ブートローダ自体の版番号（例：0.x）とは別です。ドライブ名だけでも区別できません。Cornix純正左はこの選び分けをせず、純正左用ファイルを使います。

## CoreXを更新する

1. 配列を残しておきたい場合は、右をUSBでつなぎ、Vialの **File → Save current layout** で `.vil` を保存します。
2. Vialなどの設定アプリを閉じます。更新する側だけをデータ通信対応のUSBケーブルでPCにつなぎます。
3. RESETを素早く2回押し、現れたUSBドライブに対応するUF2をコピーします。
4. コピー完了後に本体が再起動し、ドライブが消えます。USBをつなぎ替え、もう片方もv0.11.4へ更新します。
5. 左右の電源をONにし、PCへのUSBは右側につなぎます。登録済みなら同じ相手へ再接続します。初回や接続しない場合は、[固定キーで左右の登録を始めます](usage.md#左右の登録をやり直す)。左右のキー、ボール、クリック、スクロール、ダイヤルを確認します。Bluetoothで使う場合はUSBを抜いて同じ操作を確認します。

配布UF2はアプリケーション領域だけを書き込み、ブートローダと設定領域を上書きしません。v0.11.2とは保存形式を共通にしています。設定を全消去するUF2は通常配布に含めていません。

OSがドライブの取り外し通知を出しても、それだけでは失敗と判断できません。通常起動後の入力とVialの認識で確認してください。UF2をコピーできたことだけでも、全機能の動作確認にはなりません。

### v0.11.2／v0.11.3からの更新

キー配列・感度・PCと左右の登録を引き継ぐ構成です。保存形式の互換性はビルドで照合していますが、v0.11.4への更新後の実機確認はまだです。

v0.11.2から更新した場合、右のBluetooth／USB名は **Cornix TB**、Vialの表示名は **CoreX** に変わります。旧Bluetooth名が表示されても接続できる場合、再登録は必須ではありません。名前を更新したい場合や接続できない場合は、[PCと本体の両方で登録をやり直します](usage.md#pcの登録をやり直す)。左右の登録は消しません。

## Cornix純正左を初めて組み合わせる

純正ファームの左は、そのままではCoreX右と接続できません。CoreX用の **Cornix-Stock-Left v0.11.4** を左へ書き込み、右もv0.11.4へ更新します。CoreX右には純正Cornixのファームを書き込まないでください。

1. 必要な場合は、純正左をUSBでつないでVialから現在の純正用 `.vil` を保存します。
2. 純正左だけをUSB接続し、RESETを素早く2回押して `Cornix-Stock-Left-v0.11.4.uf2` をコピーします。
3. 左のUSBを外し、電池で電源をONにします。CoreX右をPCにUSB接続します。
4. [左右の登録手順](usage.md#左右の登録をやり直す)に従い、右のSpace隣の親指キー＋Hの位置を同時に5秒押します。右が青く点滅している60秒以内に、未接続の左のTab＋Tの位置を同時に5秒押します。操作する1セットだけを起動し、左右の2灯がそれぞれ緑に2秒点灯したことを確認します。
5. 左のキーで文字を入力します。右のUSBを通して入力できれば左右の接続は完了です。

電源ONやRESETでは、新しい左右の登録は始まりません。登録済みの別セットの情報が残っている場合も、同じ[固定キーの手順](usage.md#左右の登録をやり直す)を使います。初期配列を読み込む場合は[CoreX用プリセット](../keymaps/README.md)を使い、純正Cornix用の `.vil` をそのまま読み込まないでください。

純正左へ戻す場合は、メーカーが対象機種向けに配布している左用ファームと復元手順を使います。復元後は純正右と組み合わせます。このリポジトリにはメーカーの復元ファームを含めていません。

## うまくいかないとき

- **USBドライブが出ない：** データ通信対応のケーブル、USBポート、RESETの2回押しを確認します。LED点灯だけではUSB通信を確認できません。
- **更新後に起動しない：** 左右・基板・SoftDevice版を確認します。RESETの2回押しでブートローダに戻れる場合は、対応するUF2を再度コピーします。
- **左だけ反応しない：** 左の電源とファームを確認し、[左右の接続手順](usage.md#usbで接続する)を確認します。
- **設定アプリに出ない：** 書き込みモードではなく通常起動で、右をUSB接続します。複数の設定アプリやタブを閉じます。

ブートローダに戻れない場合や、基板に合うファイルが判別できない場合は、別機種用のUF2や全消去を試す前に[Issues](https://github.com/yuchamichami/CoreX-RMK/issues)へ状況を記載してください。基板名、使ったUF2の名前、OS、ドライブが出るかどうかが分かると確認できます。
