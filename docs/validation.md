# 検証状況

v0.11.4は、左右の登録を固定キーから明示的に始める方式と、その状態を示すLEDを追加した版です。実機での最終確認前のプレリリースです。新しい登録手順と成功LEDの確認には、左右ともv0.11.4への更新が必要です。

## v0.11.4の変更範囲

- 右はSpaceの隣の親指キー＋Hの物理位置を同時に5秒、未接続の左はTab＋Tの物理位置を同時に5秒押すと登録を開始します。右のキー操作はVialの割り当てに依存しません。
- 新しい相手の登録受付を60秒に限定します。電源ONやRESETだけでは受付を開きません。保存済みの相手への自動再接続は維持します。
- 受付中は親指付近の2灯が青く点滅します。登録と保存ができた場合は緑に2秒点灯、期限切れ・登録失敗時は黄色く3回点滅し、その後消灯します。左右はそれぞれの状態を表示します。
- 右は、左で初期入力の同期が終わった応答を受け取ってから緑を表示します。保存済みの旧版の左への通常再接続は維持しますが、新規登録の成功表示は両側v0.11.4で確認します。既存の通信メッセージを使い、プロトコルの列挙値や保存形式は変更しません。
- ファーム識別値は2820です。Vial UID、GPIO、キー行列、初期配列、PAW3222処理、ジェスチャー、保存スキーマと保存領域は維持します。

## 保存途中の電源断

新規の相手アドレスを保存してから入力準備を確認するため、その間の突然の電源断では相手が保存済みとして残る可能性があります。この場合も、明示操作中に選んだ相手への再接続に限られます。通常の期限切れ・通信失敗では、途中の登録を無効化します。

## v0.11.3の変更記録

v0.11.3は、CoreX右でキー・トラックボール・LEDを確認したv0.11.2を基に、版番号、右のBluetooth／USB名、Vialの表示名、配布整理を変更した版です。v0.11.3自体の実機最終確認は未実施です。

Vialの表示名は「CoreX」、Bluetooth／USB名は「Cornix TB」です。UIDは維持しました。圧縮Vial定義は2,116バイト、SHA-256は `c07519690d5c9ae5d41496d3b2f4046962259de8b169f5bacb3e755245f26a49` です。

CoreX Studioは別プロジェクトです。以下のStudio検証は分離前のv0.11.3対応時の記録であり、Studioの公開ページや公開後の動作確認を示すものではありません。

## 一般配布前の確認

一般利用向けの確定版にする前に、出荷する基板とファームの組合せで次を確認し、使ったファイルと結果を記録します。

1. 左右の全キー、ダイヤル回転と押し込み、ボール移動、クリック、スクロール。
2. USB入力とBluetooth入力、PC登録先の切り替え、USB／Bluetoothの優先出力。
3. 電源ON・RESETだけでは未登録の左右がつながらず、固定キーから登録が始まる。受付中は青く点滅し、左右の登録・保存後は緑に2秒点灯して消える。
4. 受付の60秒経過時は黄色く3回点滅して消える。第三のキーを押した場合は5秒操作が取り消され、全キーを離してから再試行できる。配列を変更しても固定位置から登録できる。
5. 左右の電源再投入後に同じ相手へ再接続し、PCの登録とキー配列が保持される。PCの登録解除と再登録、左の交換時の左右登録復旧も確認する。
6. Vialからのキー・感度・コンボなどの変更、読み戻し、電源再投入後の保持。
7. 実際に配布する版への更新、ブートローダへの再移行、更新前の設定の保持。

CoreX Studioの公開ページは、設定アプリとして別途確認します。ファームのテスト成功だけでWebページを利用可能と扱いません。
