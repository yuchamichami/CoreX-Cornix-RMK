# 検証状況

v0.11.3は、CoreX右でキー・トラックボール・LEDの動作を確認したv0.11.2を基に、名称変更と配布整理を加えた版です。v0.11.3自体は実機最終確認前のプレリリースです。

## 変更範囲

ファーム実装の差分は版番号、右のBluetooth／USB名、Vialの表示名、ビルド案内です。GPIO、キー行列、初期キー配列、2ポートのPAW3222処理、ジェスチャー、保存形式は変更していません。

Vialの表示名は「CoreX」、Bluetooth／USB名は「Cornix TB」です。UIDは維持しています。表示名変更に伴い、圧縮Vial定義は2,116バイト、SHA-256は `c07519690d5c9ae5d41496d3b2f4046962259de8b169f5bacb3e755245f26a49` になりました。

CoreX Studioは別プロジェクトへ分離します。以下のStudio検証は分離前のv0.11.3対応時の記録であり、Studioの公開ページや公開後の動作確認を示すものではありません。

## v0.11.3作成時の自動検証

- CoreX右・左のS140 6.x／7.x用と、Cornix純正左用の計5種類をビルド。
- 全UF2のアドレス・ベクタ・チェックサムを検証。ブートローダと設定領域を含まないことを確認。
- 3系統のビルドで保存スキーマ `0xA805CEFB` を照合。
- Studio（別プロジェクト）：135件成功。新旧の版・定義の取違え拒否と、行列補正を含む。
- RMK：206件成功。左右通信、USB、BLE、設定処理などを別プロセスで検証。
- ポインター処理：18件成功。2ポートの移動量・スクロールの独立性、設定変更、ジェスチャーなどを含む。
- 初期配列：9件成功。配布プリセットの全392セルを製品基板の初期値とも照合。
- PAW通信・感度・スケジューラー・LEDの単体テストも成功。

UF2のチェックサムと書き込み範囲は [manifest](../firmware/manifest.json) に記録しています。これらは自動検証であり、実機の受入確認とは区別しています。

## 実機で確認済みの範囲

以前のv0.11.2で、CoreX右の全キー、J3・J4それぞれのPAW3222入力、LEDの動作を利用者の操作で確認しています。それ以前のジェスチャー修正でも、開始キーを押してボールを動かした際のキー入力を確認しています。これらを、以下の新しい版・左右の組合せ・同時接続の確認に置き換えることはできません。

## この版では未確認の範囲

- v0.11.3を書き込んだ本体の起動、Bluetooth表示名、再接続。
- v0.11.3の左右組合せと電源再投入後の保存。
- CoreX右＋Cornix純正左、CoreX右＋CoreX左それぞれのv0.11.3での接続と登録復旧。
- S140 7.x用の実機動作。
- PAW3222を2台同時に接続した実機動作。ソフトウェアの入力経路はテスト対象です。

このため、GitHubでは実機確認前のプレリリースとして配布します。

## 一般配布前の確認

一般利用向けの確定版にする前に、出荷する基板とファームの組合せで次を確認し、使ったファイルと結果を記録します。

1. 左右の全キー、ダイヤル回転と押し込み、ボール移動、クリック、スクロール。
2. USB入力とBluetooth入力、PC登録先の切り替え、USB／Bluetoothの優先出力。
3. 左右の初回登録と再接続、PCの登録解除と再登録、左右の登録復旧。
4. Vialからのキー・感度・コンボなどの変更、読み戻し、電源再投入後の保持。
5. 実際に配布する版への更新、ブートローダへの再移行、更新前の設定の保持。

CoreX Studioの公開ページは、設定アプリとして別途確認します。ファームのテスト成功だけでWebページを利用可能と扱いません。
